## What's new

Purple branding, folder settings, animated preset previews, customizable laser/electric/plasma elements, and Photo Animation (Beta). Only Photo Animation is labelled Beta. Its painted-area effects, joint pins, background repair and reference-based blinks need careful setup for each image.

About checks for updates and displays current release notes. Downloads are verified with the Vizora updater signature before installation. Save your project before updating. The installer does not yet have a Windows Authenticode certificate.
