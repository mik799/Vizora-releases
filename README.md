[Download Vizora 0.1.13 Setup.exe](https://github.com/mik799/Vizora-releases/releases/download/v0.1.13/Vizora_0.1.13_x64-setup.exe)

Windows x64 installer for Vizora's video editor. Run Setup.exe to install or update. Portable builds and portable ZIP files are not published here.

[Release notes and checksums](https://github.com/mik799/Vizora-releases/releases/latest)

## What's new

- Drag the timeline playhead or click to seek.
- Image selection handles follow the actual media edges, fit, crop and rotation.
- Select media/audio assets, drag them to the timeline, add selected assets and remove with Undo. Original files are preserved; used assets require confirmation and locked layers are protected.
- Photo Animation is **Alpha**: easier pin placement, separate positioning/posing controls, and eye-area blinking without a mandatory reference image.
- Available updates appear in a top announcement that opens About. Updating does not require saving first.
- Purple shortcut icon refresh, clearer general-purpose welcome screen, and current release notes in About.

Photo Animation needs graphics acceleration. Complex backgrounds need careful repair; large bends can distort an image. Automatic eyelids approximate nearby skin and may need adjustment on angled or obscured faces.

Updates are verified with Vizora's updater signature before installation. Unsaved work may be lost when installing. The installer does not yet have a Windows Authenticode certificate.

Application source remains private. This repository contains release information and installers only; GitHub's automatic source archives are not Vizora application source. Projects and media are processed locally.
